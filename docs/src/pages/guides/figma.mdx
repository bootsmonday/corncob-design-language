## Figma

If you want to use the Corncob Design Language tokens in your Figma projects, you can follow these steps to integrate them seamlessly.
These tokens represent the design system's color, typography, spacing, and other style properties, making it easy to maintain consistency across your Figma projects.

### Token JSON files

- Light mode tokens <a href={`${base}assets/figma/corncob.light.tokens.json`}>tokens-light.json</a>
- Dark mode tokens <a href={`${base}assets/figma/corncob.dark.tokens.json`}>tokens-dark.json</a>

### Steps to Integrate

1. Open your Figma project.
2. Go to the "Variables" panel and click on the "Collections" icon.
3. Select "Import" and choose the Corncob Design Language token file.
4. Once imported, you can apply the tokens to your design elements directly from the "Styles" panel.

### Notes
A couple notes on CSS-to-Figma token translation:
- Not all CSS properties have a direct equivalent in Figma tokens.
  - '50%' needed to be converted 9999 for circular corners.
  - Box shadows / Focus Rings needed to be broken down into individual layers for Figma.
- Some complex CSS values may need to be simplified or adjusted for Figma.
- Ensure that your design elements in Figma are using the imported tokens consistently to maintain design system integrity.
