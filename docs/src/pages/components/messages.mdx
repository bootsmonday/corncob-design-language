## Messages

Messages are used to display important information to the user, such as informational, success, error, or warning messages.

In the examples below, you should make sure the heading (`<h*>`) tags within the message are appropriately nested within the page's heading structure.

### When to Use

Messages should be used when you need to communicate important information to the user that is relevant to the entire page or section. They are ideal for providing feedback on actions that affect the overall page, such as form submissions, system notifications, or critical alerts.

### When Not to Use

Messages should not be used for trivial information or messages that are only relevant to a small part of the page. Avoid using messages for minor notifications that do not require the user's immediate attention, as this can lead to message fatigue and reduce the effectiveness of important alerts.

### Page Level Messages

Page level messages are used to display important information about the page. They are typically displayed at the top of the page or section and can be used to provide feedback to the user about their actions, such as form submissions or system notifications.

## React Variants

- **Success:** Green message indicating a successful action.
- **Warning:** Yellow message indicating a warning situation.
- **Error:** Red message indicating an error.
- **Info:** Blue message indicating informational content.
