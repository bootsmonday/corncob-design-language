## Overview

Badges are small UI elements that provide contextual information or status indicators to the user. They are typically used to highlight key information, such as notifications, status updates, or categorical labels. An icon isn't required but may be included to visually reinforce the meaning or context of the badge.

### When to Use

Badges should be used when you need to provide users with quick, at-a-glance information about the status or context of an element. They are particularly useful for highlighting notifications, indicating the state of an item, or categorizing content without taking up significant space in the UI. Use badges sparingly to avoid overwhelming the user with too much information.

### When not to Use

Badges should not be used when the information can be conveyed through other UI elements more effectively, or when overuse would clutter the interface and overwhelm the user. Avoid using badges for non-critical information or for decorative purposes that do not provide meaningful context.

Neutral badges are used to indicate a neutral state or status to the user, without implying success, warning, error, or informational context.
