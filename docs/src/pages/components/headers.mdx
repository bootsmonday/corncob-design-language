## Overview

Headers are used to provide structure and hierarchy to your content. They help users understand the organization of information and navigate through your application. Headers set the tone for the page and establish a clear visual hierarchy, guiding users to the most important elements first. Navigation elements within the header should be easily accessible and clearly indicate the current context. 

### When to Use Headers

Headers should be used at the top of your pages or sections to provide context and navigation options. They are ideal for displaying the company logo, page title, and primary navigation links, ensuring users can easily understand the structure of your application and access key areas quickly.

### When Not to Use Headers

Navigation Headers do not need to be used on splash pages, modal dialogs, or other contexts where the primary navigation is either unnecessary or already provided through alternative means. In such cases, including a header may add unnecessary visual complexity without providing meaningful navigation benefits.

Do:

- start from the canonical header markup above
- replace placeholder content and icons after the structure is in place
- use `corn-button-bar` and `corn-popover--anchor corn-button-bar--more` as documented when the header includes overflow navigation

Do not:

- wrap the required direct children in a custom brand container
- move `corn-header--title` inside `corn-company`
- replace the documented navigation button classes before the canonical header works
