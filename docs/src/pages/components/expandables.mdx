## Overview

Expandables allow hiding and showing content, reducing UI clutter by letting users reveal additional details on demand. Common patterns include accordions, collapsible panels, panel menus, and tree views.

Corncob's `<corn-expandable>` web component builds on native [`<details>`/`<summary>` elements](https://developer.mozilla.org/en-US/docs/Web/HTML/Element/details). This provides excellent accessibility and performance—no JavaScript needed for basic expand/collapse.

However, native elements lack smooth height transition animations. `<corn-expandable>` adds these via JavaScript-driven CSS class toggling on open/close.

### When to Use

Use expandables when you want to hide non-critical content by default, allowing users to reveal it on demand. Ideal scenarios include FAQs, detailed settings panels, and sections with supplementary information that doesn't need to be immediately visible. Avoid using expandables for essential content that users must see to understand the page context.

### When Not to Use

Avoid using expandables for content that is critical for understanding the page context or for actions that users must take immediately. Hiding essential information can lead to confusion and reduce the overall usability of your interface.

Always ask yourself if the user is likely to want to collapse the content. It is generally better to keep content visible by default unless there is a clear benefit to being able to hide it. Adding controls that aren't used creates unnecessary visual noise.

### Usage

The component requires:

- `<corn-expandable class="corn-expandable">`
- Inside: `<details slot="details">`
  - `<summary class="corn-expandable-button">` (header + icon)
  - Content in `<div class="corn-expandable--content">`

Corncob's CSS handles the expand/collapse animation by toggling classes on the content div when the details element opens/closes.

### Default (Closed)

<corn-expandable class="corn-expandable">
  <details slot="details">
    <summary class="corn-expandable-button">Summary<SpriteIcon name="chevron-right" className="corn-icon" /></summary>
    <div class="corn-expandable--content">
      <div>
        <h3>heading</h3>
        <div>content</div>
      </div>
    </div>
  </details>
</corn-expandable>

## Accordion (Single Open)

Wrap multiple in `<div class="corn-accordion">`. 
Add the same `name` attribute to each `<details>` element. The `name` attribute should be unique for each accordion group for mutual exclusivity, same as native details behavior.

  <div class="corn-accordion">
    <corn-expandable class="corn-expandable">
      <details slot="details" name="corn-single">
        <summary class="corn-expandable-button">Summary<SpriteIcon name="chevron-right" className="corn-icon" /></summary>
        <div class="corn-expandable--content">details</div>
      </details>
    </corn-expandable>
    <corn-expandable class="corn-expandable">
      <details slot="details" name="corn-single">
        <summary class="corn-expandable-button">Summary 2<SpriteIcon name="chevron-right" className="corn-icon" /></summary>
        <div class="corn-expandable--content">details 2</div>
      </details>
    </corn-expandable>
    <corn-expandable class="corn-expandable">
      <details slot="details" name="corn-single">
        <summary class="corn-expandable-button">Summary 3<SpriteIcon name="chevron-right" className="corn-icon" /></summary>
        <div class="corn-expandable--content">details</div>
      </details>
    </corn-expandable>
  </div>

## Nested / Tree View

Supports recursion. Add `corn-tree-view` class for styling.

  <corn-expandable class="corn-expandable corn-tree-view">
    <details slot="details">
      <summary class="corn-expandable-button"><SpriteIcon name="chevron-right" className="corn-icon" />Summary</summary>
      <div class="corn-expandable--content">
        <corn-expandable class="corn-expandable corn-tree-view">
          <details slot="details">
            <summary class="corn-expandable-button"><SpriteIcon name="chevron-right" className="corn-icon" />Summary 2</summary>
            <div class="corn-expandable--content">More details</div>
          </details>
        </corn-expandable>
      </div>
    </details>
  </corn-expandable>
