## Select Input

The select input component is a form element that allows users to choose one or more options from a dropdown list. It is commonly used in forms where users need to select from a predefined set of options.

The select input component is built using the `corn-select` custom element, which provides a consistent and accessible user interface for selecting options. The component supports various sizes, including `xs`, `sm`, `md`, `lg`, and `xl`, allowing developers to choose the appropriate size for their form layout.

The corn-select supports single and multiple selection modes, placeholder text. It is populated with options using the standard HTML `<option>` element.

## Size Modifiers

The default size for the select input is `md`, but it can be modified to `xs`, `sm`, `lg`, or `xl` using the corresponding class on the `corn-select` element.

- `corn-select--xs`
- `corn-select--sm`
- `corn-select--md`
- `corn-select--lg`
- `corn-select--xl`

### Extra Small (xs)

The `xs` size is the smallest size available for text inputs. It is designed for use in compact spaces where a smaller input field is needed.
This should not be used as the default size for text inputs, but it can be used in specific contexts where space is limited, such as in a table or a navigation bar.

<div class="corn-form--item">
  <div class="corn-select corn-select--xs">
    <corn-select id="select--xs" name="select" placeholder="Select an option...">
      <option value="option1">Option 1</option>
      <option value="option2">Option 2</option>
      <option value="option3">Option 3</option>
    </corn-select>
    <label for="select--xs" class="corn-assistive-text">
      Select Label
    </label>
  </div>
</div>
