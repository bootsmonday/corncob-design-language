## Overview

Checkboxes are used to allow users to select one or more options from a set. They can be used in forms, settings, and anywhere else where multiple selections are needed.
Corncob checkboxes are standard HTML checkboxes styled to fit the Corncob design system.
They can be used in various states such as checked, unchecked, and disabled.

### When to Use Checkboxes

Checkboxes should be used when users need to select one or more options from a set. They are ideal for scenarios where multiple selections are allowed, such as preferences, settings, or multi-select forms. The options should also be relatively simple and short in length to ensure clarity and ease of use. Group related checkboxes together under a clear and concise label to provide context and improve usability.

### When Not to Use Checkboxes

Checkboxes should not be used when only a single selection is allowed, as radio buttons or toggle switches are more appropriate in such cases. Avoid using checkboxes for actions that do not represent a selection state.

### Indeterminate Checkboxes

Indeterminate checkboxes are used to indicate a state that is neither checked nor unchecked.
This is commonly used when a checkbox represents a parent selection that has some, but not all, of its child checkboxes selected.
The indeterminate state is set via JavaScript on the checkbox input element using the `indeterminate` property.

### Task Checkboxes
A checklist is a group of checkboxes that are visually connected to indicate that they belong together. Checklists are often used for task lists, where each checkbox represents a task that can be marked as complete. Corncob provides a specific style for task checkboxes to differentiate them from regular checkboxes.
